☁️ Nimbus: A cinematic weather dashboard built using HTML, CSS, and JavaScript.  
Nimbus provides real-time weather updates with a cozy glassmorphism UI inspired by dreamy landscapes and modern weather applications.

🌦️ Features
- 🔍 Search weather by city
- 🌡️ Real-time temperature updates
- ☁️ Dynamic weather conditions
- 💨 Wind speed & humidity display
- 🕒 Hourly forecast section
- 📅 5-day forecast cards
- 🎨 Aesthetic glassmorphism UI
- 🌄 Scenic responsive background
- ⚡ Powered by OpenWeather API

🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Font Awesome Icons
- Google Fonts
